    給其他擴充：用指令發送通知
    
// 發送到預設聊天室
await ctx.commands.execute('telegram.send', '備份完成');

// 指定聊天室（名稱或 chat_id）、HTML 格式、靜音
await ctx.commands.execute('telegram.send', {
  text: '<b>站台異常</b>\nhttps://example.com 回應 503',
  html: true, chat: '維運群組', silent: false,
});

// 發送附檔
await ctx.commands.execute('telegram.send', {
  file: { filename: 'report.csv', content: 'a,b\n1,2', mime: 'text/csv' },
  caption: '日報',
});
// 回傳 { ok: true, chat, messageIds }；失敗時丟出錯誤

    
畫面上的「分享」會先預覽、由使用者選聊天室；指令則直接發送，不經確認。
